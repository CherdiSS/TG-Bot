# Telegram-бот для приёма заявок в клининговую компанию

> **Демонстрационный проект для портфолио.** Цены и контакты в боте вымышлены и приведены для примера.

## Что делает бот

Бот принимает заявки на уборку прямо в Telegram:

1. Показывает главное меню: **«Оставить заявку»**, **«Услуги и цены»**, **«Контакты»**, **«Помощь»**.
2. Пошагово (7 шагов) собирает заявку:
   - имя;
   - телефон или Telegram-контакт (можно отправить номер одной кнопкой);
   - тип уборки — inline-кнопками (поддерживающая, генеральная, после ремонта, мытьё окон, другое);
   - площадь помещения в м²;
   - район или адрес;
   - желаемые дату и время;
   - комментарий (можно пропустить).
3. Показывает итоговую заявку и просит подтвердить.
4. После подтверждения отправляет заявку администратору в личные сообщения.
5. При отмене предлагает начать заново или вернуться в главное меню.

Дополнительно:

- проверяет введённые данные (пустые значения, формат телефона, площадь — положительное число);
- реагирует на неверный ввод: фото вместо текста, текст вместо кнопки, нажатие на устаревшие кнопки;
- позволяет прервать заполнение в любой момент кнопкой «❌ Отменить» или командой `/cancel`;
- если заявку не удалось доставить администратору, сообщает об этом пользователю и сохраняет данные, чтобы можно было повторить отправку.

## Для какого бизнеса подходит

Клининговые компании и частные клинеры. После небольших правок — любые сервисы с выездом к клиенту: химчистка мебели и ковров, мастер на час, вывоз мусора, мойка окон, дезинсекция и т. п.

## Установка

Нужен **Python 3.11+**.

```bash
cd cleaning-bot
python -m venv .venv

# Linux / macOS
source .venv/bin/activate
# Windows
.venv\Scripts\activate

pip install -r requirements.txt
```

## Как получить токен через BotFather

1. Откройте в Telegram [@BotFather](https://t.me/BotFather).
2. Отправьте команду `/newbot`.
3. Введите название бота (например, «Чистый дом — заявки»).
4. Введите username бота, он должен заканчиваться на `bot` (например, `chisty_dom_demo_bot`).
5. BotFather пришлёт токен вида `1234567890:AAH...`. Это пароль от бота — никому его не показывайте и не публикуйте в репозитории.

## Как узнать свой Telegram ID

ID нужен, чтобы бот знал, кому отправлять заявки.

- Напишите любое сообщение боту [@userinfobot](https://t.me/userinfobot) — он ответит вашим числовым ID (например, `123456789`).
- Либо используйте [@getmyid_bot](https://t.me/getmyid_bot).

## Настройка

Скопируйте пример настроек и заполните его:

```bash
cp .env.example .env      # Windows: copy .env.example .env
```

```env
BOT_TOKEN=токен_от_BotFather
ADMIN_ID=ваш_числовой_ID
```

Файл `.env` добавлен в `.gitignore` и не попадёт в репозиторий. Вместо файла можно задать обычные переменные окружения с теми же именами.

## Запуск

```bash
python bot.py
```

В консоли появится строка `Бот запущен...`. Остановить бота: `Ctrl+C`.

> **Важно:** администратор должен хотя бы раз написать боту `/start`. Иначе Telegram не разрешит боту отправить ему сообщение первым, и заявка не дойдёт (пользователь увидит сообщение об ошибке, а в консоли появится запись в логе).

## Как протестировать сценарий заявки

Удобнее всего проверять с двух аккаунтов (администратор и «клиент»), но можно и с одного — тогда заявка придёт вам же.

1. **Основной сценарий.** `/start` → «📝 Оставить заявку» → пройдите все 7 шагов → «✅ Подтвердить». Заявка должна прийти в чат с администратором.
2. **Проверка валидации:**
   - имя из пробелов или одних цифр → бот попросит ввести имя ещё раз;
   - контакт `12345` → ошибка; `+7 900 123-45-67`, `89001234567`, `@username`, `t.me/username` → принимаются;
   - кнопка «📱 Отправить мой номер» → номер подставляется автоматически;
   - площадь `-5`, `0`, `abc` → ошибка; `45`, `62,5`, `60 м2` → принимаются.
3. **Неверный ввод:**
   - на шаге выбора типа уборки напишите текст вместо нажатия кнопки → бот попросит выбрать кнопкой;
   - отправьте фото или стикер вместо ответа → бот попросит ответить текстом;
   - на шаге подтверждения напишите текст → бот напомнит о кнопках.
4. **Отмена:**
   - во время заполнения нажмите «❌ Отменить» или `/cancel` → появятся кнопки «🔄 Начать заново» и «🏠 Главное меню»;
   - на итоговой заявке нажмите «❌ Отменить» → заявка не отправляется.
5. **Устаревшие кнопки.** После отмены или отправки нажмите кнопку в старом сообщении → бот сообщит, что кнопка неактивна.
6. **Разделы меню.** Проверьте «💰 Услуги и цены», «📞 Контакты», «❓ Помощь».

## Какие скриншоты сделать для портфолио

Лучше снимать с телефона — так видно, что кнопки удобны на мобильном.

1. Приветствие и главное меню.
2. Раздел «Услуги и цены».
3. Шаг с выбором типа уборки (inline-кнопки).
4. Сообщение об ошибке валидации (например, неверная площадь или телефон).
5. Итоговая заявка с кнопками «Подтвердить» / «Отменить».
6. Сообщение «Спасибо! Заявка принята».
7. Заявка, пришедшая администратору.
8. Экран после отмены с кнопками «Начать заново» / «Главное меню».

Для превью удобно собрать 3–4 скриншота в один коллаж: меню → выбор услуги → итоговая заявка → уведомление администратору. Используйте тестовые данные, а не реальные телефоны.

## Ограничения демо-версии

- Состояния хранятся в памяти (`MemoryStorage`): при перезапуске незаконченные диалоги сбрасываются. Для продакшена стоит подключить `RedisStorage`.
- Заявки не сохраняются в базу данных — только отправляются администратору.
- Дата и время вводятся свободным текстом, без календаря.

## Технологии

Python 3.11+, aiogram 3.x (Router, FSM, inline- и reply-клавиатуры), python-dotenv.
