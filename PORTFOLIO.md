# Telegram-бот для приёма заявок в клининговую компанию

**Тип:** демонстрационный проект (не коммерческий заказ). Цены и контакты в боте условные.

## Задача

Показать, как небольшая сервисная компания может принимать заявки через Telegram: клиент заполняет короткую анкету, а администратор сразу получает готовую заявку в личные сообщения — без звонков и переписки для уточнения базовых деталей.

## Что реализовано

- Главное меню: «Оставить заявку», «Услуги и цены», «Контакты», «Помощь».
- Пошаговая анкета из 7 шагов: имя, контакт, тип уборки, площадь, адрес, дата и время, комментарий.
- Выбор типа уборки inline-кнопками; отправка номера телефона одной кнопкой.
- Проверка данных: имя, формат телефона или @username, площадь — положительное число.
- Обработка ошибок: текст вместо кнопки, фото вместо текста, нажатие на устаревшие кнопки, сбой отправки администратору.
- Итоговая заявка с подтверждением перед отправкой; отмена на любом шаге с выбором «Начать заново» / «Главное меню».
- Уведомление администратору со ссылкой на профиль клиента.
- Настройки (токен, ID администратора) — в переменных окружения.
- Код разделён на модули: точка входа, обработчики, клавиатуры, состояния, конфигурация.

## Технологии

Python 3.11+, aiogram 3.x (FSM, Router, inline- и reply-клавиатуры), python-dotenv.

## Как проверить работу

1. `pip install -r requirements.txt`
2. Создать бота через @BotFather, узнать свой ID через @userinfobot.
3. Скопировать `.env.example` в `.env` и указать `BOT_TOKEN` и `ADMIN_ID`.
4. `python bot.py`, написать боту `/start` и оставить тестовую заявку — она придёт на указанный ID.

Подробный сценарий тестирования описан в README.

## Что можно расширить в реальном заказе

- Хранение заявок в базе данных (SQLite/PostgreSQL) и выгрузка в Google Таблицы или CRM (amoCRM, Bitrix24).
- Отправка заявок в рабочий чат менеджеров и смена статуса заявки кнопками («Принята», «Выполнена»).
- Предварительный расчёт стоимости по типу уборки и площади.
- Выбор даты и времени через календарь со свободными слотами.
- Загрузка фото помещения клиентом.
- Напоминания клиенту накануне уборки и запрос отзыва после неё.
- Админ-панель: редактирование цен и текстов без правки кода.
- RedisStorage для FSM и запуск через webhook и Docker на сервере.
